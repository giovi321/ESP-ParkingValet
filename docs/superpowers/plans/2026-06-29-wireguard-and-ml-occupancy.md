# WireGuard Remote Access + ML Occupancy Classifier — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the device reachable remotely over WireGuard, then replace the single-feature edge-threshold occupancy decision with a lightweight multi-feature classifier trained on the device's own camera data — so weather-robust detection can be developed and iterated entirely from outside the LAN.

**Architecture:** Two independent, sequentially-shippable parts on branch `dev-ml`. **Part A (WireGuard)** adds a `droscy/esp_wireguard` client that joins the homelab VPN after NTP sync, exposing the existing web UI/OTA on the tunnel IP. **Part B (Classifier)** extends the existing per-ROI loop in `cv.cpp` to emit a feature vector, runs a tiny embedded classifier (trained offline in Python from device-logged features), and keeps the current edge engine as a selectable fallback + disagreement monitor.

**Tech Stack:** C++ / Arduino-ESP32 2.0.17 (PlatformIO `espressif32@6.9.0`), ESP-IDF 4.4, `droscy/esp_wireguard@0.4.5`, ArduinoJson 7, built-in synchronous `WebServer`; host-side Python 3 + scikit-learn + `m2cgen` for the offline trainer.

Design spec: `docs/superpowers/specs/2026-06-29-ml-occupancy-classifier-design.md` (read it before starting).

## Global Constraints

- **Board/toolchain (exact):** plain ESP32 (LX6, no SIMD), 8 MB PSRAM; `platform = espressif32@6.9.0`, `framework = arduino` (Arduino-ESP32 2.0.17 / IDF 4.4). Do not assume ESP32-S3.
- **Flash budget:** `min_spiffs` partitions, two ~1.9 MB OTA app slots. Current `firmware.bin` ≈ 1.23 MB. Keep the app well under ~1.9 MB; report `.bin` size after each part.
- **Single-threaded loop:** the `WebServer` + camera + everything runs on the `loopTask`; a core-0 monitor reboots if `loop()` makes no progress for ~90 s. No task may block `loop()` for seconds. The camera runs continuous DMA into PSRAM, which rides the flash cache — never write flash while the camera is live (OTA already `esp_camera_deinit()`s first).
- **Secrets:** credential fields are stored in NVS and MUST be masked by `configToJson(..., includeSecrets=false)` and only overwritten by `configMergeJson` when the incoming value is non-empty. Never emit a secret over the API.
- **Generated web UI:** `src/web_ui.h` is generated from `web-src/index.html` by `tools/gen_web_ui.py` (pre-build hook in `tools/pio_prebuild.py`). NEVER hand-edit `src/web_ui.h`. Edit `web-src/index.html`, then it regenerates on `pio run`.
- **Commits:** Conventional Commits. Every commit message ends with a trailing line:
  ```
  giovi321
  ```
- **WireGuard rules (from feasibility research):** NTP-gate the handshake (do not connect until `clockSynced()`); `PersistentKeepalive = 25`; on failure to come up, **reboot** rather than churn connect/disconnect; the homelab server peer's `AllowedIPs` MUST include the device's tunnel IP.
- **Build command (firmware verification):** `pio run` (compiles + links + builds `.bin`). Flash over USB with `pio run -t upload`, or OTA-upload `.pio/build/esp32cam/firmware.bin` via the web UI. On-device serial: `pio device monitor` (115200).

## Shared Contracts (Part B firmware ⇄ Python must agree exactly)

**Feature vector** — fixed length `CLF_NFEAT = 16`, `float feat[16]`, computed per bay over the bay's decoded luma + RGB565 pixels. Index order is canonical and identical in firmware and Python:

| idx | name | definition |
|---|---|---|
| 0 | `edge` | mean of `|∇x|+|∇y|` over in-polygon luma pixels (the current `sr.edge`) |
| 1 | `relEdge` | `edge - baselineEdge` (the adaptive empty baseline; current relative metric) |
| 2 | `meanI` | mean luma 0..255 (the current `sr.meanI`) |
| 3 | `stdI` | std-dev of luma over in-polygon pixels |
| 4..13 | `lbp[0..9]` | 10-bin **uniform LBP(8,1)** histogram, normalized so the 10 bins sum to 1 |
| 14 | `meanSat` | mean saturation 0..1, `(max(r,g,b)-min(r,g,b))/max(r,g,b)` from RGB565 (0 if max=0) |
| 15 | `meanBR` | mean of `(b - r)/255` in -1..1 (wet/asphalt vs snow/sky cue) |

**Model header** — `src/clf_model.h` is generated by the Python trainer and consumed by firmware. Stable interface:

```c
#pragma once
// Generated by tools/train_classifier.py — do not edit by hand.
#define CLF_NFEAT 16
#define CLF_MODEL_PRESENT 0   // 1 once a real model is embedded; 0 = placeholder (firmware falls back to edge engine)
// Occupied probability in [0,1] for a CLF_NFEAT-long feature vector.
// In the placeholder this returns -1.0f and must not be trusted (guarded by CLF_MODEL_PRESENT).
static inline float clfPredict(const float* feat) { (void)feat; return -1.0f; }
```

**Config field names (final):**
- WireGuard: `wgEnabled` (bool), `wgPrivateKey` (secret), `wgAddress` (str, e.g. `10.6.0.7/32`), `wgPeerPublicKey` (str), `wgEndpointHost` (str), `wgEndpointPort` (uint16), `wgAllowedIps` (str, e.g. `10.6.0.0/24`), `wgPresharedKey` (secret), `wgKeepalive` (uint16, default 25).
- Classifier: `occupancyEngine` (uint8: 0 = edge-threshold legacy, 1 = trained classifier), `trainCapture` (bool), `captureUrl` (str), `captureAuthHeaderName` (str), `captureAuthHeaderValue` (secret).
- New SECRET fields (must be in `configToJson` masking, `configMergeJson` non-empty guard, and the web UI `SECRET[]` list): `wgPrivateKey`, `wgPresharedKey`, `captureAuthHeaderValue`.

```cpp
#include "wg.h"
#include <esp_wireguard.h>
#include <WiFi.h>
#include "clk.h"
#include "logbuf.h"

static const Config*    s_cfg = nullptr;
static wireguard_ctx_t  s_ctx = {0};
static wireguard_config_t s_wg = ESP_WIREGUARD_CONFIG_DEFAULT();
static bool      s_inited = false;     // esp_wireguard_init done
static bool      s_connected = false;  // esp_wireguard_connect issued
static bool      s_up = false;
static uint32_t  s_connectedAt = 0;    // millis() when connect was issued
static uint32_t  s_lastPoll = 0;
static const uint32_t WG_UP_TIMEOUT_MS = 60000;  // reboot if peer never comes up

void wgBegin(const Config* cfg) { s_cfg = cfg; }

static bool wgConfigComplete() {
  return s_cfg && s_cfg->wgEnabled &&
         s_cfg->wgPrivateKey[0] && s_cfg->wgPeerPublicKey[0] &&
         s_cfg->wgEndpointHost[0] && s_cfg->wgAddress[0];
}

const char* wgStateStr() {
  if (!s_cfg || !s_cfg->wgEnabled) return "off";
  if (!s_connected) return clockSynced() ? "connecting" : "wait-clock";
  return s_up ? "up" : "down";
}
bool wgIsUp() { return s_up; }

void wgLoop(uint32_t now) {
  if (!wgConfigComplete()) return;
  if (WiFi.status() != WL_CONNECTED) return;     // only over STA
  if (!clockSynced()) return;                    // NTP gate (TAI64N)

  if (!s_connected) {
    // Fill config from NVS. wgAddress is "ip/cidr"; split into address + the wg
    // lib's expected fields. Keep it simple: store the bare IP in wgAddress and a
    // /32; if you keep CIDR, parse it here.
    s_wg.private_key          = s_cfg->wgPrivateKey;
    s_wg.public_key           = s_cfg->wgPeerPublicKey;
    s_wg.endpoint             = s_cfg->wgEndpointHost;
    s_wg.port                 = s_cfg->wgEndpointPort;
    s_wg.address              = s_cfg->wgAddress;        // bare device tunnel IP, e.g. "10.6.0.7"
    s_wg.netmask              = "255.255.255.0";
    s_wg.persistent_keepalive = s_cfg->wgKeepalive;
    if (s_cfg->wgPresharedKey[0]) s_wg.preshared_key = s_cfg->wgPresharedKey;

    if (!s_inited) {
      if (esp_wireguard_init(&s_wg, &s_ctx) != ESP_OK) { log_e("wg init failed"); return; }
      s_inited = true;
    }
    if (esp_wireguard_connect(&s_ctx) != ESP_OK) { log_e("wg connect failed"); return; }
    s_connected = true; s_connectedAt = now;
    log_i("wg: connecting to %s:%u", s_cfg->wgEndpointHost, (unsigned)s_cfg->wgEndpointPort);
    return;
  }

  // Poll peer status at ~5 s cadence (cheap).
  if (now - s_lastPoll < 5000) return;
  s_lastPoll = now;
  bool up = (esp_wireguardif_peer_is_up(&s_ctx) == ESP_OK);
  if (up && !s_up) log_i("wg: tunnel up");
  s_up = up;

  // Reboot-on-failure: never came up within the timeout -> recover via reboot
  // rather than churn connect/disconnect (avoids the library teardown race).
  if (!s_up && (now - s_connectedAt) > WG_UP_TIMEOUT_MS) {
    log_w("wg: peer not up after %lus -> reboot", (unsigned long)(WG_UP_TIMEOUT_MS / 1000));
    delay(50);
    ESP.restart();
  }
}
```

- [ ] **Step 2: Write `src/features.h`.** Defines the accumulators gathered in the pixel loop and the finalize step that produces the canonical 16-float vector.

```cpp
#pragma once
#include <Arduino.h>

static const int CLF_NFEAT = 16;

// Accumulated over a bay's in-polygon pixels in one pass (see cv.cpp).
struct FeatureAccum {
  uint32_t cnt;          // pixel count
  uint64_t gradSum;      // sum of |gx|+|gy|
  uint64_t intSum;       // sum of luma
  uint64_t intSqSum;     // sum of luma^2 (for variance)
  uint32_t lbp[10];      // uniform LBP(8,1) histogram (bins 0..8 = #set-bits for uniform codes, bin 9 = non-uniform)
  int64_t  satSum_x1000; // sum of saturation*1000 (integer-friendly)
  int64_t  brSum;        // sum of (b - r)  (each -255..255)
};

inline void featureAccumInit(FeatureAccum& a) { memset(&a, 0, sizeof(a)); }

// Produce the canonical CLF_NFEAT vector. baselineEdge is the bay's adaptive empty
// reference (SlotResult.baselineEdge / _baselineEdge[i]).
inline void featuresFinalize(const FeatureAccum& a, float baselineEdge, float* feat) {
  float n = a.cnt ? (float)a.cnt : 1.0f;
  float edge  = (float)a.gradSum / n;
  float meanI = (float)a.intSum  / n;
  float meanSq= (float)a.intSqSum / n;
  float var   = meanSq - meanI * meanI; if (var < 0) var = 0;
  feat[0] = edge;
  feat[1] = edge - baselineEdge;
  feat[2] = meanI;
  feat[3] = sqrtf(var);
  uint32_t lbpTot = 0; for (int k = 0; k < 10; k++) lbpTot += a.lbp[k];
  float lt = lbpTot ? (float)lbpTot : 1.0f;
  for (int k = 0; k < 10; k++) feat[4 + k] = (float)a.lbp[k] / lt;
  feat[14] = (float)a.satSum_x1000 / (n * 1000.0f);
  feat[15] = (float)a.brSum / (n * 255.0f);
}
```

```cpp
        fa.intSum  += lum;
        fa.intSqSum += (uint32_t)lum * (uint32_t)lum;
        fa.cnt++;
        // uniform LBP(8,1): compare 8 neighbours to centre (guard image borders)
        if (x > 0 && x < w - 1 && y > 0 && y < h - 1) {
          const uint8_t* r0 = &_luma[(y-1)*w];
          const uint8_t* r1 = row;
          const uint8_t* r2 = nxt;
          uint8_t c = lum;
          uint8_t code =
            ((r0[x-1] >= c) << 7) | ((r0[x] >= c) << 6) | ((r0[x+1] >= c) << 5) |
            ((r1[x+1] >= c) << 4) | ((r2[x+1] >= c) << 3) | ((r2[x] >= c) << 2) |
            ((r2[x-1] >= c) << 1) | ((r1[x-1] >= c) << 0);
          // uniformity = number of 0->1/1->0 transitions in the circular 8-bit code
          uint8_t rot = (uint8_t)((code << 1) | (code >> 7));
          uint8_t diff = code ^ rot; int trans = __builtin_popcount(diff);
          if (trans <= 2) fa.lbp[__builtin_popcount(code)]++;  // uniform -> bin by set-bits 0..8
          else            fa.lbp[9]++;                          // non-uniform
        }
        // colour from the matching RGB565 pixel
        uint16_t cpx = px[y * w + x];
        int cr = ((cpx >> 11) & 0x1F) << 3, cg = ((cpx >> 5) & 0x3F) << 2, cb = (cpx & 0x1F) << 3;
        int mx = cr > cg ? (cr > cb ? cr : cb) : (cg > cb ? cg : cb);
        int mn = cr < cg ? (cr < cb ? cr : cb) : (cg < cb ? cg : cb);
        fa.satSum_x1000 += mx ? (int64_t)(mx - mn) * 1000 / mx : 0;
        fa.brSum += (cb - cr);
```

Keep the existing `gradSum`/`intSum`/`cnt` (used by `edge`/`meanI`) OR read them from `fa` — to stay DRY, set `edge = (float)fa.gradSum/fa.cnt` and `meanI = (float)fa.intSum/fa.cnt` and delete the old locals. After the loop, before the decision, build the vector:

```cpp
    sr.clfScore = -1.0f;
```

```cpp
void captureMaybeLog(const Config& cfg, const CvResult& r) {
  if (!cfg.trainCapture || !cfg.captureUrl[0] || !r.valid) return;
  String body; body.reserve(256 + r.n * 220);
```
